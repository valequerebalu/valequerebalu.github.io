# valequerebalu.github.io

Portafolio personal construido con HTML5, CSS3 y JavaScript vanilla. Es un sitio estático que presenta mi perfil, experiencia, stack tecnológico y proyectos.

## Estructura del proyecto

```text
valequerebalu.github.io/
├── index.html
├── README.md
└── assets/
    ├── css/
    │   ├── base.css
    │   ├── layout.css
    │   └── components.css
    ├── img/
    │   ├── deporte.jpeg
    │   ├── graduacion.jpeg
    │   ├── lectura.jpeg
    │   ├── perfil_portafolio.png
    │   ├── perfil_web.png
    │   └── viajes.jpeg
    └── js/
        ├── main.js
        ├── data/
        │   └── projects.js
        └── ui/
            └── ui.js
```

### Descripción

- `index.html`: estructura y contenido de las secciones del portafolio.
- `assets/css/`: estilos separados en reglas base, distribución de página y componentes visuales.
- `assets/img/`: fotografías e imágenes utilizadas en el sitio.
- `assets/js/main.js`: punto de entrada de los módulos JavaScript.
- `assets/js/data/projects.js`: datos que se muestran en la sección de proyectos.
- `assets/js/ui/ui.js`: módulo destinado a la presentación y actualización de elementos de interfaz.

La separación de JavaScript organiza el frontend del portafolio; no representa una arquitectura de backend. Los proyectos enlazados en el sitio son los que permiten mostrar experiencia en desarrollo backend.
